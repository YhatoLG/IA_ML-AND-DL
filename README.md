Objetivo principal: Aplicar técnicas de machine learning y deep learning para tareas de predicción, utilizando datos reales.

🔍 Contenido Inicial del Notebook
Importación de librerías:
Se importan bibliotecas esenciales para ciencia de datos y machine learning, incluyendo pandas, numpy, matplotlib, scikit-learn, y scipy.

Lectura de datos:
Se accede a un conjunto de datos desde un enlace a datos abiertos del gobierno colombiano (https://medata.gov.co). En particular, se trata de un archivo CSV de nombre sivigila_bpn.csv, probablemente relacionado con vigilancia en salud pública.

Modelos incluidos:

Regresión logística y lineal

KMeans (clustering)

Evaluación de modelos mediante métricas como accuracy, RMSE y R²
